# 强情绪增量案例层

用途：仅在现有主库生成结果过于理性、泛化或重复，而当前脚本又有明确情绪事实时补充一种新结构。它不是新的主规则，不得改变输出格式、题眼排序、事实保真或安全边界。

## 一、调用硬门

同时满足以下条件才读本文件：

1. 当前脚本明确出现身份吃亏、真实白买／亏钱、脏累动作、高嫌弃动作被取消、一次改造长期少做事或意外设计；
2. 这份事实能够逐字回指当前脚本，不靠虚构亲测、身体结果或普遍结果；
3. 主库连续3条句壳仍只能得到泛化、重复或机器味表达；
4. 本篇尚未使用补充库原始标题。

每篇最多1组使用本文件中的原始标题。补充层不得把主库最强题眼挤出方案1；只有补充表达比现有候选更准、更自然时才保留。

## 二、A层：可作为原始爆款对标的增量句壳

### E-A01 身份吃亏
- 原始标题：`还是一胎妈妈的钱好骗🚫618推车避坑指南❗️`
- 逐字句壳：`还是[明确身份]的钱好骗｜[具体品类]避坑`
- 句壳家族：`身份损失`
- 边界：脚本必须有该身份已经踩坑、白买或交学费的事实；不得用来责备没有经历的目标人群。

### E-A02 具体动作被取消
- 原始标题：`换床单不用拆围栏？丸丫安全感和便捷双在线！`
- 逐字句壳：`[高频旧动作]不用[麻烦步骤]？[产品/结构][可观察价值]`
- 句壳家族：`动作取消`
- 边界：必须能说清旧步骤和新动作；不迁移原题中的安全评价。

### E-A03 一次处理长期少做事
- 原始标题：`一次动脑 一直躺平‼️超绝懒人烟机柜收纳`
- 逐字句壳：`一次[具体动作] 一直[持续少做的事]｜[具体场景]`
- 句壳家族：`长期减负`
- 边界：必须存在一次改造或设置，且后续确实减少一个反复动作；`一直躺平`不能脱离动作证据单用。

### E-A04 有画面的旧痛苦
- 原始标题：`告别举铁式带娃｜学会做减法`
- 逐字句壳：`告别[有画面的旧痛苦]｜[新的明确判断或动作]`
- 句壳家族：`痛苦命名`
- 边界：比喻必须来自真实动作、重量或麻烦；不能靠身体伤害夸大。

### E-A05 短态度整治小麻烦
- 原始标题：`专门整治鸡毛蒜皮。`
- 逐字句壳：`专门整治[一类具体小麻烦]`
- 句壳家族：`短态度`
- 边界：脚本必须至少给出一个具体小麻烦和产品怎样处理；不能把`整治鸡毛蒜皮`当万能家居标题。

### E-A06 鸡肋状态逆袭
- 原始标题：`自制果蔬拉篮🔥30cm鸡肋柜逆袭‼️太香了`
- 逐字句壳：`[具体动作]｜[尺寸/对象]鸡肋[空间/物品]逆袭`
- 句壳家族：`鸡肋逆袭`
- 边界：旧状态、改造动作和新结果必须完整；尺寸和金额不得估编。

### E-A07 明确数量＋强嫌弃
- 原始标题：`养娃踩坑实录！5件网红母婴用品纯纯鸡肋`
- 逐字句壳：`[阶段/身份]踩坑实录！[数量][具体对象]纯纯鸡肋`
- 句壳家族：`浪费嫌弃`
- 边界：数量必须与正文逐项对应；`纯纯鸡肋`只用于已有闲置、白买、占地方等事实。

### E-A08 阶段劝停＋购买顺序
- 原始标题：`618 母婴别乱囤❗宝宝前三月囤货超全清单`
- 逐字句壳：`[购买节点][品类]别乱囤｜[阶段]按[顺序/周期]买`
- 句壳家族：`阶段止损`
- 边界：必须有真实阶段、购买时机和闲置事实；不能只凭促销节点制造焦虑。

### E-A09 即时惊叹
- 原始标题：`人怎么能聪明到这种程度`
- 逐字句壳：`人怎么能聪明到这种程度`
- 句壳家族：`即时惊叹`
- 边界：只能用于一个确实反常识、能被画面或动作证明的设计；没有具体意外点时弃用。

### E-A10 高嫌弃动作被取消
- 原始标题：`懒人党救星！终于不用刷马桶了`
- 逐字句壳：`[明确人群]！终于不用[高嫌弃高频动作]了`
- 句壳家族：`嫌弃动作取消`
- 边界：产品必须真实接管该动作；不能把减少频率写成完全不用。

### E-A11 真实时长＋生活态度
- 原始标题：`实住一年｜我家不劳动思路（一镜到底）`
- 逐字句壳：`[真实使用时长]｜我家[鲜明生活态度]`
- 句壳家族：`长期态度`
- 边界：时长和本人经验必须真实；态度需要至少一个具体少劳动设计承接。

## 三、A层：只迁移情绪机制，不作为原始爆款字段

以下句子来自正文事实或审核重组，不得写入`对标小标题（原始爆款）`：

- `一胎不懂，硬生生亏了五位数`：用于识别`身份＋已发生损失`，金额必须来自脚本；
- `做辅食做到指甲缝里全是菜泥`：用于识别`脏累触感＋旧步骤`，不能把正文句冒充原始标题。

它们只帮助把抽象的`费钱、省妈、解放双手`改成具体损失或动作，最终成品仍需从真实句壳或原生结构生成。

## 四、B层：迁移库

B层只借关系，不自动进入对标字段；当前脚本证据完整且表达自然时才可原生生成：

- `养娃半年！这些全都白买了！`：借`明确阶段＋白买结果`；
- `占地仅1m²！180+搞定娃的衣柜+喂养台`：借`小空间＋真实预算＋两个任务`；
- `倒垃圾终于不用碰恶心的盖子边边了`：借`具体嫌弃动作被取消`；
- `终于不用举着手机追娃跑了`：借`反复旧动作被取消`，这是正文事实，不是原始爆款标题。

B层不能仅凭原句真实就升级为A层，也不能在同一篇中与A层补充句壳同时使用。

## 五、C层：本轮明确不补

以下方向继续遵循现有主库与否决规则，不因“网感词”重新放行：

- `智商税、割韭菜、1K／2K／3K差在哪、低价对高价`，但没有身份损失或生活代价；
- `后悔没早买、终于被它收服、别瞎囤、出门像搬家、邪修`只有常见热词，没有新事实关系；
- `一件顶五件、省妈、解放双手、真香`没有具体被取消的旧动作；
- 纯数字省钱、空间或配置，没有主观反应、旧麻烦和完成证据；
- 方向正确但与同篇已保留方案重复，只换近义词。

## 六、与现有稳定版的优先级

发生冲突时固定按以下顺序处理：

1. `quality-and-safety.md`事实与安全门；
2. 当前脚本最强购买题眼；
3. 现有主库公式和标题句壳；
4. 本文件A层补充句壳；
5. 本文件B层迁移关系。

补充层只能增加一个可选方向，不能删除、改写或降级任何已有能力。
