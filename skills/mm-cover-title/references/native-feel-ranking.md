# 题眼优先与自然语感排序卡

用途：在候选已经通过事实、主体、风险、产品闭环和字数硬门后，先判断有没有说中消费者题眼，再决定哪一组排第一、是否值得继续输出下一组。

## 一、先判断题眼

题眼是目标消费者看到这篇内容时，真正想问、犹豫或需要改变判断的那件事。候选先过三问：

1. 这是消费者真实会关心的问题吗？
2. 当前脚本真的在回答它吗？
3. 封面是否自然、直接地把它说出来了？

三问有一项不成立，不能因为有测试画面、情绪词或脚本原话就排在前面。

## 二、网感的可检查定义

网感不是流行词，也不等于必须写出强烈反应。它首先是把真实购买问题说得准、说得自然，让用户扫一眼就知道为什么值得点开。

题眼成立后，再检查以下加分项：

1. **脚本独有**：包含当前脚本才有的动作、物件、数字、场景、对话或反差，不能无修改套到五种别的产品；
2. **画面可见**：能被拍出来或在脑中形成画面，但画面必须服务购买题眼，不能只展示广告动作；
3. **情绪真实**：像消费者当下会说的话，有惊讶、窝火、不服、嫌弃、松口气、好奇或明确站队；没有强情绪时，准确的问题和判断仍可成立；
4. **口气自然**：读出来像人在说话，不像课程目录、参数摘要、广告口号或后台结论；
5. **点击有因**：用户能知道点开会得到什么判断、差异或具体收益。

## 三、可用点击题眼

只选当前脚本确实支持的题眼，不强行凑齐：

- **价格差**：同类价格跨度大，用户想知道钱差在哪里；
- **错误标准**：用户容易盯错一个具体指标，脚本给出新的判断；
- **使用麻烦**：钱、时间或物品被浪费，有具体场景承接；
- **信息差**：包装、配方、结构或使用条件里藏着影响判断的差异；
- **价值判断**：贵不等于好、便宜不等于差、长期使用和一次体验的区别；
- **结果反差**：一个看似矛盾的结果由当前脚本事实承接。

`攻略、清单、实测、对比、怎么选、看几点`是内容形式，不是题眼。

## 四、排序顺序

硬门全部通过后再排序：

1. 消费者问题与脚本主交付是否对得上；
2. 表达是否自然、直接，不端着、不像广告表演句；
3. 是否具体到当前品类、标准、价格、场景或差异；
4. 用户点开后能得到什么是否清楚；
5. 画面和情绪是否自然加强前四项；
6. 与已保留方案是否回答不同问题；
7. 前六项相近时，才看句壳轮换、数字形式和结构新鲜度。

画面不能越级。一个画面很具体，但与消费者主要购买问题关系弱，仍排在题眼准确的自然判断之后。

## 五、句式不定罪

不能只看句式判断是不是套话：

```text
尿裤别只看吸量 → 具体指出错误标准，可以成立
几毛到八块一支 / 宝宝钙差在哪 → 具体价差对应购买疑问，可以成立
买东西别只看参数 → 没有当前品类和具体冲突，属于套话
看5点选对宝宝钙 → 只有方法数量，没有说出用户真正犹豫什么
```

`别乱买、认准、怎么选、看几点、攻略、清单、靠谱、照着买、必看`没有具体对象和冲突时，同一批最多保留一组；只概括正文目录时直接淘汰。

`别只看`和`差在哪`不自动降级。它们后面说清了具体错误标准或差异，并且正是脚本主交付时，可以排第一。

## 六、多组停止规则

先保留最强的一组。只有下一组同时满足以下条件才继续：

1. 通过全部硬门；
2. 使用不同的事实关系或点击理由；
3. 回答不同的消费者问题；
4. 不是最强方案的弱化版；
5. 单独拿出来也达到可直接排版的质量。

任一项不成立就停止，不预设三组，也不为了情绪种类凑组。

## 七、尴尬感否决

候选出现以下任一情况，即使有画面或情绪也淘汰：

- 像为了展示文案能力硬写的广告句，真人不会自然使用；
- 把测试动作本身当成消费者必须关心的题眼；
- 用拟声词、拟人、口号或比喻抢走了真正购买问题；
- 上下排各自有画面，但合起来没有清楚的购买判断；
- 需要点击机制说明才能解释为什么值得点。

例如`气泡呼呼往外冒 / 透气不是嘴上说`有测试画面，但表达像广告演示口号，且没有`尿裤别只看吸量`那样直接命中选购问题，不应仅凭画面排在前面。

## 八、禁止伪造网感

- 不靠`绝绝子、封神、闭眼入、上大分、硬控、神器`或叹号堆叠制造情绪；
- 不为了“有情绪”扩大事实、制造恐惧或功效承诺；
- 不把资料整理、包装参数对照、表格比较写成`实测`；
- 不让风险提醒挽救仍然错误的候选，错误候选必须先删除或重写；
- 不把情绪名称写进封面，情绪应从具体问题和语气里自然产生。
