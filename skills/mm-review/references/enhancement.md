# 内容增强与篇幅

日期：2026-10-16
对应版本：meimei-draft-review v1.4.0（2026-10-30 增补好物合集类型、逐件开法、说辞去重、选购条件、分组）

在主流程第 7 步（定增强方式和篇幅）读取。用于已经定位了观看问题、需要决定怎么加强、各段讲多长的时候。广告与日常都可用；广告仍以 [广告审核](advertising.md) 的推荐逻辑为准。

## 一、什么算加强

加强的结果是：观众多了一个具体的想看、想要或想照做的理由。下面几种不算加强：

- 只删减、合并、调顺序，句子更顺了，但想要的理由没有变多
- 只加“救命、巨巨巨好用、绝了”等情绪词
- 把一件写得很透，却让整篇拖长、后面的段落没人看完

有效做法通常是把已有素材换个位置或说具体，例如：

- 原稿结尾的一句代价（“被叮得睡不着”），提到对应产品前面当困扰
- 原稿段尾的一句处境（“终于不用边推车边扇扇子”），提到段首，先让人想起自己的狼狈
- 原稿的回购、备两支这类行为，放在效果之后当证据，夸奖放最后
- 开头提前埋下作者自己给某件起的称呼或结果，正文到那里兑现

这些是机制示例，不移植到别的稿件。每处增强都要说得出四件事：取自哪段材料、放在哪、改善哪个观看问题、正文怎样兑现。

## 二、可选的增强方式

这是编辑分类，不是爆款配方，也不是完整清单。不按用了几种打分；一段可以同时起几种作用。

| 方式 | 起什么作用 | 无效用法 |
|---|---|---|
| 明确收益 | 观众知道看完能得到什么具体结果或判断 | 只说干货满满、值得收藏 |
| 具体困扰与代价 | 观众认出自己正在经历的麻烦 | 泛泛焦虑、夸大后果 |
| 新奇与意外用途 | 用法或搭配出乎目标观众预期 | 把没见过直接说成全网新奇 |
| 反差 | 前后、贵与值、小与多的对照让价值醒目 | 只加极端形容词 |
| 认知修正 | 对常见判断给出有依据的新解释 | 为反常识编错误结论 |
| 选择冲突与两难 | 展示真实取舍，让人想知道怎么决定 | 编争吵、拉踩 |
| 悬念与信息缺口 | 先给一部分，让人想知道原因或结果 | 说“最后一个绝了”却不兑现 |
| 生活画面与感官代入 | 用熟悉的动作、触感让描述可感受 | 堆“舒服、丝滑、清爽” |
| 可见演示与结果 | 用过程或结果直接展示差异 | 把拟拍镜头写成已测结果 |
| 情绪释放与幽默 | 把心疼、惊喜、无奈写进具体处境 | 一连串“巨好用”没有新增理由 |
| 身份与关系共鸣 | 观众认出自己的角色处境 | 只贴“宝妈”标签、挑对立 |
| 可执行、可回查的收获 | 看完能用、以后还会查的步骤或条件 | 只报知识点，没有行动条件 |
| 转述价值 | 能转给家人、帮别人解释一件事 | 强喊转发 |
| 当下时机 | 对应眼前的季节、阶段或共同议题 | 生硬贴热点，把旧热度当现在 |

没有素材支持的新奇、反差、结果或经历，不能为了增强而编造。

## 三、情绪词的位置

情绪词和夸奖要有具体理由撑着。两种放法都可以：先给理由、后夸（听完困扰和效果再听到“巨好用”，有底气）；或者先亮态度、紧接着证明（“绝对是我心中妆前喷雾的第一名”，下一句就讲为什么）。不行的是只有“巨好用”，后面没有理由，或者理由隔了好几句才来。原稿先亮态度、后面确实证明了的，保留原顺序，不为了规则挪到后面。

文案要有情绪张力，不等于要求作者高声口播。

## 四、篇幅与详略

- 默认整篇不超过原稿篇幅。加强一处，就压掉重复背景、空总结或第二次说同一好处的句子来换。新加的选购条件、分组转场句算在篇幅里，同样用压掉的句子来换；「【可以这样加】」补段不算篇幅，因为学员要换成自己的经历后再整合。
- 原稿明显过短、缺关键段，学员补料后需要多写，或者压完仍然超出，可以增加，在成稿开头那句话里说明增加了什么、为什么。
- 合集超过 5 件时，先选出重点件，数量看素材，常见 3—5 件：新奇的、学员有具体使用细节或孩子反应的、价格高需要说服的优先。重点件把推荐理由写足；其余每件压短，只留它最尖的一个点，原句写得再顺也压。长短差多少，看这件需要解释多少，常见是两倍左右，不按倍数凑。5 件以内可以件件讲足。不能每件平均对待。评级避坑（夯到拉、红黑榜）和品牌选购类不按这条压：评级稿每件本来就短，靠等级加一两句理由推进；品牌选购按品类讲，每类写足选购条件即可。
- 后排加快靠省背景、合并重复、让画面承担信息，每件仍保留它最关键的一个理由，不能只报名字。
- 开头埋了期待的那一件，放在后面也要兑现，但不必展开最长。

改稿时可在内部估算原稿与改稿各段字数；不向学员展示字数表。

## 五、好物合集逐件检查

### 先认合集类型

| 类型 | 观众要什么 | 注意 |
|---|---|---|
| 清单种草（几件各有用处） | 每件为什么值得买 | 按本节逐件检查；重点件写足、其他件压短 |
| 场景清单（一次出行、一个季节、一个阶段） | 这个场景下缺什么、怎么备 | 件数多时按场景里的问题分组；有自然顺序的按顺序 |
| 评级避坑（夯到拉、红黑榜、踩坑） | 哪些买、哪些不买、为什么 | 每件短，等级后面必须有理由；常给替代方案和购买数量限制；不按两倍规则压 |
| 品牌选购（按品类推品牌） | 不同预算买哪个、怎么挑 | 价位分档、选购条件、误区纠正是核心；有立场的判断保留 |

每件至少能从原句或已提供画面中指出：

- **推荐理由**：什么人、什么时刻，会因为哪一点想要它
- **产品与理由的关系**：哪个特点、动作或用法带来这个好处
- **支撑**：个人体验、演示、已有产品资料或作者的选物判断；不强制每件补经历
- **可记住的表达**：具体动作、感受、反差或画面，让这件区别于泛泛介绍

结果分“已说清／说了但弱／缺材料”，对应原句和改法。

重点件改完要让观众知道“为什么是它”，不只告诉观众这件有什么。“往上推一层”是常用的一种：先点出观众常见的选法、用法或误区，再给这件的不同（引导）。它不是每件必用：原稿已有直接演示、感官比较、一次取舍或意外用途能说清“为什么是它”的，用原稿的，不硬加一句“很多人会买××”。例如先说“很快会厌倦的声光玩具”再说安抚玩偶，先说“新手妈妈会被可爱的小奶瓶吸引”再给容量建议。品类层面的做法对比、送礼寓意、使用场景、选择条件可以直接写，不写成作者亲历、不贬低别的品牌；具体产品之间谁更耐用、更好用的比较必须来自原稿；作者感受、孩子反应、使用结果只用原话，原话里没有就用「【可以这样加】」补一句。只把原句理顺、删掉夸张词，不算加强。

用“往上推一层”时有几种形式，按原稿材料挑，作者自己试过的比泛泛说“很多人会买”更可信：

- **同类通病**：“很多妆前喷雾用量一多就黏、浮在脸上”，再说这件不会（木三）
- **普通款对比**：“普通皮筋扯头发宝宝疼得鬼哭狼嚎”，再说这根（小美）
- **试过的办法不行**：“想换水龙头口，拆半天型号对不上”，再说这个一套就上（野阿洗）
- **误区纠正**：“学步鞋不是为了学走路，是走得很好了再买”（晶晶）；“千万别买豆豆被，看着暖和但不透气”（阿飘）

### 每件换一种开法

种草力不够，常见原因是每件都用同一种开法、同一套说辞：件件“这个真的巨好用”“特别方便”“省妈神器”。对标样本每件的开法都在换，常用的有：

| 开法 | 例子（只学手法） |
|---|---|
| 一句判断或地位 | “绝对是我心中妆前喷雾的第一名”（木三） |
| 圈人 | “只要你们家有女宝宝，这个一定要买”（小美） |
| 一个糟心时刻，带点自嘲 | 以前洗澡衣服没地方放，“拎个塑料袋挂马桶上”（野阿洗） |
| 先说难点，再给答案 | 洗澡想听歌，音响放哪？“花洒上啊姐妹们”（喵哒） |
| 价格锚 | “10 块钱一个的车载小挂钩”（闹妈） |
| 别人的反应 | “两个朋友来我家以后，回去就买了”（野阿洗） |
| 意外用途 | 厨房不锈钢板铺在浴室台面；汽车地垫当猫砂垫（喵哒、野阿洗） |
| 给它一个角色或比喻 | “看似是个猪鬃梳，实则是个随身理发师”（罗OK） |
| 先认缺点或门槛 | “这类假睫毛一推荐火了品控就出问题，这个我买了三次都稳定才来推荐”（木三） |
| 直接演示 | “你看，拉开衣服一丢，放手它就关上”（野阿洗、闹妈） |

用法：

- 相邻两件不用同一种开法。改完把每件的第一句排在一起读一遍，读着像同一个句式的，换掉其中一句。
- 开法要从原稿材料里来：原稿有价格才用价格锚，有朋友跟买才用别人的反应，不为了换花样编材料。原稿里的“日常好物先说推荐理由”仍然成立（见美美的判断第 11 条），上面这些开法都要在前一两句内带出推荐理由。
- **说辞去重**：先分清两类词。
  - **作者有个性的说法**：自己的梗、比喻、带画面的话（“钱包鼓的别点进来”“疼得鬼哭狼嚎”“当场发霉自杀”）。按第一档第 2 条保护，不受去重限制。
  - **通用夸奖词**：“巨好用、真的绝了、闭眼入、宝藏、省妈、方便、谁用谁知道、必备”这类。不限次数，原稿的照常保留；只要求前后有一句具体理由撑着（好在哪、替你省了哪一步）。夸奖词前后都没有理由的，先补理由。
  - 同一个词连着好几件都在用、念着重复时，可以换掉其中几处，二选一，是建议不是硬性要求：
    1. 换成这件具体好在哪。几件都只说“方便”时，写清方便在哪个动作上（不用弯腰、一套就上、放手就关）。
    2. 换一个更新鲜、更有劲的夸法，例如“皇帝级好物”“夯爆了”“我家的镇宅之宝”。语气贴合作者平时的说话方式，不用作者不会说的网络词。
  - 不为了去重把原稿的夸奖词删光，口气要留住。

### 留下观众能带走的东西

重点件在原稿有材料时，至少留一个观众看完能照着做的东西：选购条件（“桶要够深、有座位、有溢水孔，不一定买同款”）、尺寸或数量（“按自家牛奶盒大小买”“马甲三四件换着穿就够”）、价位分档（性价比的、好一点的、买到顶的）、用法提醒（“小号的刮玻璃和镜子”）。原稿没有的不编；属于常识性选购标准的，可以用「【可以这样加】」补一句。

### 缺点、门槛和适合谁要保留

原稿里的缺点、价格偏高、使用门槛、“比较适合装修中的”“对颜值要求高的”这类话，作用是帮观众判断，原样保留，不为了种草力删掉。可以调位置：先讲推荐理由，再讲门槛和适合谁。

删掉“没有宝宝能拒绝”这类空夸时，要换上一个更具体的理由，不能只删不补。几件都重复“方便、省妈”时，每件只留最有辨识度的一点。

整篇再看：开头要有价值点，也要有种草感（美美原话：“好物分享的开头要有点价值点，还得有种草感”）。种草感可以来自作者原有的情绪词、口气、一个具体反差或一句态度，不要求第一句同时塞进情绪词和价值点，两三句内都有就行。价值点可以是这份清单帮观众解决什么具体麻烦（例如送礼怕撞、怕不体面），也可以是这份清单为什么值得听（花了多少、用了多久、只选什么样的、一次真实经历、别人的反馈），入口和写法见 [开头吸引力与具体改法](opening.md) 第四节；“看这一篇就够了”“分享几个好物”只是交代主题。首件是否尽快给出实质价值；中间各件是否各有新信息；后排节奏是否合适；结尾是否完成推荐。序号、品名漏掉或乱掉时补齐，观众要跟得上第几件。

## 六、排品

排品候选数量由内容决定：有两个就给两个，只有一个就给一个，没有明显适合前置的就说明。每个候选说明吸引点、与主题的关系、已有材料和缺少的画面。不能因为段落最长、故事最完整就默认适合放第一。

几条排序依据指向不同时，按这个先后：

1. **观众要按顺序才看得懂的**（行程、月龄、步骤、一天里的使用时刻）：按自然顺序；下面几条只在组内用。按场景分出来的组（随身、酒店、自驾）不算自然顺序，组的先后按强弱排，最强的一组在前。
2. **头两件**放最能证明这份清单不一样的：新奇的、讲法不常规的、作者最有把握能当场演示的（“我的得意之作”）。两件不能是同一种好处；第一件要兑现开头说的话。最强的一件放这里，不留到压轴。
3. **热度**只在第 2 条分不出先后时参考，取得方法见下文。
4. **意外用途、之前分享过但很合主题的，可以压轴**，前提是前面几件已经给足观看理由。

合集 8 件以上，按观众的问题分成两三组，每组开头用一句话交代这组解决什么，这句话本身就是新的观看理由。转场句只说这组解决什么，不带夸奖（“没带过的不知道多香”），不为接上一件硬造因果（“娃能自己安静画，也得有双愿意自己穿的鞋”）。分组不代替分重点件：8 件以上重点件最多 5 件，其余每件压到一两句。例如“洗舒服了是首要，真正的考验是洗完之后那一摊”（喵哒），“接下来是能让宝宝安安静静坐车 12 个小时的耐玩玩具”（闹妈）。

合集排序可以参考热度：被很多人推荐过的、讲法又常规的往后放，新奇、少见的往前提。热度只是参考之一：常见的东西如果原稿讲出了不常规的用法或说法，可以放前面（美美原话：“前面 2 个一定要不那么常规的，或者可以是常规的，但你的话要说的不常规”）。Agent 自己不知道当前哪些产品火，不能凭印象说“已经被推烂了”。按下面的顺序取得判断：

1. **先从学员自己的话里找**：写了“人手一个”“妈圈人手一辆”“网红款”的，说明推的人多，可以往后放（“必备”多半只是口头禅，不当作热度证据）；写了“绝对是你没见过的”“很少见”“小众”“第一次知道”的，说明新奇，往前提。
2. **稿子里看不出时，不提问**，按稿子已有线索先排，在排品理由里说明依据（例如“稿子里看不出哪件更常见，先按你写得最具体的排前面”）。
3. **联网不是必经步骤**。环境能搜索、学员也希望时可以参考，搜到的结果只作参考，不当成确定的热度。

排序理由写明依据，例如“你写了妈圈人手一辆，说明推的人多，放到后面”，不说成“现在全网都推烂了”。只给文字时说明“基于当前稿子”；有用户提供的画面才说“基于稿子和画面”。热度只影响先后，被推得多的也照样写足它的推荐理由。

## 七、补料

补料在改法形成之后问，因为这时才知道缺的是哪一句。只影响某一件、某一句的补料，放在成稿的“待确认”里问，不放进方向单；方向单最多一个问题，见 SKILL.md 第一档第 4 条。

- 先把已有材料能改好的部分改好，不假定学员什么都没给
- 只问会让某句写不实的缺口，说明补完替换哪一句、篇幅会不会变
- 问法具体到一次使用，例如“最近一次带出去用，具体怎么拿出来、怎么涂？哪一步比之前省事？没有特别感受也可以直接说”
- 没补就保留原句，不硬写比较和孩子反应
- 缺的是常识性做法而不是个人经历时，按主流程第 8 步（查缺口）直接补一段，用「【可以这样加】」标出，请学员换成自己的经历后发回
- 数量按必要性压缩，最多 2—3 条，按影响大小排；不为每件逐项问一遍
- 学员没补，就保留「【可以这样加】」示范段和原句，标明“没补就按现在的发”，不反复追问
