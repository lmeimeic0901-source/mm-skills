# 升维审稿

第一轮写“问题在哪一层”“刷到的人会怎么想”时读；学员回“查卡审”时读第三节。升维管“问题在哪一层”，美美的短视频脑反应理论管“为什么不好”：刷到的人会依次经过 认出来（这跟我有关）→ 停下来 → 等下去 → 拿到手 → 记得住、会行动，哪一步走不下去，问题就在对应的那一层。五步只在心里用，回复里不写“第几关”。判断拿不准时，对照 [审稿示例](review-examples.md)。

## 一、问题在哪一层：每层只问一个问题

日常：选题角度 → 开头 → 结构 → 句子。
广告：广告切入点 → 开头 → 卖点 → 结构 → 句子。

从上往下问，答得上来就往下走；答不上来、并且指得出是哪一句让刷到的人走不下去，问题就在这一层，停下。下面的层只点会让人直接划走的。指不出原句，就当这一层没问题。

1. **选题角度（日常）／广告切入点（广告）**：刷到的人认得出“这是给我的”吗？看完能带走什么？
   - 走不下去的样子：不知道给谁看；几个意思并列或前后打架（前面在抱怨，结尾又在劝别人去做）；话都对，但都是基础常识，看完没有收藏的理由（没有判断依据、没有信息差、没有“试了不行怎么办”）。
   - 广告还要问：产品为什么在这个人的这个处境出现；靠“直到我发现”硬接，或只剩卖点清单，判这一层。
   - 伪合集（合集形式里藏一个合作产品）按好物广告审：合作产品不用顶到开头，也不用放第一件。
2. **开头**：刷到的人看完前几句，有没有一个往下看的理由？理由有一个成立就算过，不用样样都有：
   - 跟我有关：圈出人群、处境，或正在烦的具体麻烦
   - 能得到东西（价值点）：种草承诺（“看完没法空手走”）、一张清单、一个办法、避坑
   - 还缺一块想知道：反常结果、只说了一半、“没几个人推荐过”
   - 凭什么信你：花了多少、用了多久、前后对比、别人的反应
   - 想听这个人说：人设、口气、网感
   - 有问题的只有三种：一个理由都没有；有理由，但埋在第三四句以后；只报了题，后面没有价值点。“分享几个巨好用的好物”这类报题本身是开头的一种，不算错。
   - 开头没力气时先问：原稿里有没有能撑起开头的料？有（埋在后面、第一句没写好），判这一层；没有，或要换一种讲法才找得到，判选题角度／广告切入点。
   - 具体好不好，对照 [开头吸引力与具体改法](opening.md) 和美美盲标过的开头标准样本。
3. **卖点（只有广告）**：看完知道为什么要买它吗？选的是不是这个人最在乎的点？有没有变成他能感受到的场景和感受，而不是硬报参数和背书？
   - 走不下去的样子：先讲的不是最戳人的那个；卖点并排夸、没有递进；只在念功能、配方、背书；功能前面讲过了，产品出场又念一遍；卖点顺序不是“用的时候先碰到什么”。
   - 开头放背书可能是品牌要求，不判错；看背书之后有没有按观众的顺序讲。
4. **结构**：每一段有没有新东西，让人愿意看到最后？
   - 删除测试：删掉这一段，刷到的人少得到什么？少不了，就是多余的。
   - 走不下去的样子：同一个意思换句话又说一遍；前提放在最后（该先说的“全家统一”压在方法后面）；帮人做判断的稿没有统一的选择标准；最有分量的料要挪段、重排才用得上。
5. **句子**：读着顺不顺、像不像真人、有没有一个记得住的点？
   - 空夸张：不具象、只有情绪的大话（“用完整个人都被治愈了”）。种草渲染、微微夸张（“宝藏好物”“天花板”）不算问题。
   - 像 AI 写的：太光滑、太完整，矫情、共情过头的现成套话，真人聊天不会这么说。
   - 暴露广告感的怪句：替品牌说出了缺点（“别看它价格不便宜”）。
   - 只在说功能，缺种草的情绪和画面。
   - 网感梗、方言口气、口播里的数字说法（“像有个32号技师给你拖着”“买过56套”＝五六套）是人设，不算问题。

好稿：五层都走得通，最高判到句子，最多点一两处。不为显得有用硬挑问题，也不因为是好稿就一条都不说。

## 二、刷到的人会怎么想

每条写成：“原句（十几个字以内）”——谁：看到会怎么想，一行写完。

- 谁：广告选目标买家、品牌审核人；日常选刷到的路人、评论区、想照着做的人；都可以加“看过很多同类内容的人”（查套路、查同质化）。按稿子挑最相关的，不必每种都写。
- 怎么想：只写对着这句原句说得出的反应，例如会划走、看不懂、觉得在说教、觉得是硬广、会在评论区质疑、照着做会出问题、觉得和别人一样、看完不知道能拿来干什么。
- 不写“作为粉丝我会觉得……”这类说不出原句的感受；不预测流量、点赞，也不判断品牌最终会不会通过。

## 三、卡审：默认不查，学员回“查卡审”才查

第一轮和成稿都不查卡审，不写卡审提示。只在学员回“查卡审”，或自己问“会不会卡审”“能不能过审”时才查。

查的时候只看两类，其他一律不提：

1. 口服、医疗类讲明显功效（吃了能治、能防病、不吃就会怎样）。
2. 绝对说法：全国第一、权威顶级、国家级、保证百分之多少有效这类，把排名、认证、效果说成绝对的客观事实。

学员主动要查，就认真查这两类，原稿和成稿逐句过一遍，最多 3 条。第 2 类不管是不是品牌给的都要提：只要出现“第一”“免检”“国家级”“顶级”“百分之多少以上”这类把排名、认证、效果说绝对的词，就提。

用“我”的口吻说的感受、分享、人设和网感，作者自己家的做法，产品的使用感受和功能描述，品牌给的普通数据和认证（照原样说、没有绝对词的），种草夸张（“天花板”“绝了”），都不提。

写法：“这句可能卡审，可以换成……”，给一个说法：改成自己的感受、自己家的情况，或加个画面代替说出来；不问出处。只提示，不改判断，不动成稿；学员说要改再改。没有就直说“这两类说法没有，可以放心发”。

## 四、改动范围跟着层走

方向单永远是同一个样子：问题在哪一层、刷到的人会怎么想、推荐改法（一段一行）、其他方向。层只决定推荐改法里动多少：

| 最上面的问题在 | 推荐改法动到哪 |
|---|---|
| 句子 | 顺序不动，只改那一两句 |
| 开头 | 换开头，加上后面因此接不上、要压短或补一句的段 |
| 卖点 | 重选、重排卖点，把卖点变成场景和感受 |
| 结构 | 重排段落 |
| 选题角度／广告切入点 | 换讲法后的新顺序 |

- 主线成立时问题层最高写到结构或卖点，不写选题角度／广告切入点。
- 开头换了，后面要接得住：铺垫重复的压短，承接断了的补一句；不受影响的段写“顺序不动”，不硬改。
