# 日常笔记审核｜按内容任务选择判断

仅用于主要承担非合作内容任务的稿件。出现商品或品牌不自动算广告；商业关系不清且会改变审核标准时，先问清。以下是从不同类型历史改稿提炼的**编辑判断**，不是所有笔记都要套一遍的结构。

## 先做三件事

1. 用一句话说清：什么处境的人，为什么看这一篇，看完具体得到什么。把标题、首帧／开头、正文和结尾与这个承诺对齐。标题说“怎么选”，正文就要有判断标准；标题说“我的经历”，正文就要有真实过程和变化。
2. 找到原稿最值得保留的东西：真实现场、作者独有的判断、有效清单或时间线。先确认问题是入口弱、内容空、顺序乱，还是承诺本身无材料支撑；不要见到“爆款”目标就整篇重写。
3. 做“正确但空”的检查：去掉那些人人都能说的正确总结后，还剩下什么可观察的信号、具体动作、取舍条件、例外处理或独有经历？如果剩不下，优先补**已有材料能证实的**细节，不靠大词、焦虑或语气加重制造收获感。历史阶段切换稿保留快节奏，重点补“试了不接受怎么办”；三岁能力稿把多层口诀改成一幕亲子互动。

## 口述内容先看成熟度

“口述”是输入方式，不是必须大改的理由。区分已经按完整脚本说出的口播、表达基本完整但重复／顺序乱的初稿，以及边想边说的经历或观点素材。

| 口述内容的实际情况 | 处理 |
| --- | --- |
| 主旨、顺序和信息都清楚，仅有赘词或弱开头 | 清理赘词、局部修改，保护已有效的原句 |
| 主旨清楚、素材足够，但反复绕回、铺垫太长或信息散 | 合并重复、重排段落，必要时重写开头与衔接；保留事实、观点和个人口气 |
| 同时在讲不同主题，无法判断作者最想表达哪一件事 | 提出已有材料支持的主要方向，并问一个最关键的选择问题后再完成全文 |
| 只有题目、大观点或情绪，缺少支撑正文的具体材料 | 问最关键的一件事或一个判断，先给可确定部分；不靠虚构经历补齐完整稿 |

### 散乱口述的处理顺序

1. **先提原意与材料**：提取作者想讲什么、已有经历／观察／动作／观点／变化及有个人味道的原句。转写重复和语气词可以删，犹豫、幽默或感受若承载意思应保留。疑似转写错误不能擅自改成新事实。
2. **确定本篇要讲的一件事**：按原材料选择有内容支撑的主要问题，不把几段不相关的观点硬拼。原意清楚就用一句话说明本次整理方向并继续；有实质歧义才追问，不为每篇增加先确认再写稿的等待。
3. **重新安排顺序**：按观众理解所需的关系组织，而不是照口述发生的顺序。例如经历稿按困扰、选择、转折和感受组织；攻略按实际选择问题和判断条件组织。只保留有作用的背景、重复内容合并，原本有效的结构可继续用。
4. **确定有吸引力的开头**：从已有材料寻找具体困扰、真实反差、选择两难、转折、意外结果或有分歧的判断，明确观众会为什么停下、接着想听什么。不能只把主题或共同用途提前就认定完成。按 [开头吸引力与具体改法](opening.md) 检查并选择入口，再让正文兑现。原第一句若只是“我今天想说一下”或长背景，可删除。开头的承诺不能超出正文已有材料。
5. **写成稿并反查**：保留作者原意、真实经历和语气，核对新开头是否得到正文回应、删背景后是否仍能理解、重排后有没有改错因果或新增对话／效果。缺关键材料时明确待补，不假装完整。

### 开头具体怎样改

分类帮助理解正文要完成什么，实际开头须按 [开头吸引力与具体改法](opening.md) 判断，不能给每类配一个平直介绍句。

- 经历／故事：从真实材料中提炼反差、两难、转折或意外结果，让人想知道为什么发生、后来怎么处理；可以把解释后置，保留理解该事所需的背景，不虚构冲突。
- 攻略／清单：让读者立即识别正在犹豫的选择、容易忽略的代价或具体麻烦，并期待后面的判断办法；正文须确有对应条件与做法。
- 观点：呈现具体生活中的分歧、令人想追问原因的判断或有依据的意外结论；原材料支撑观点，避免平直说教和代入式权威反转。
- 合集：在共同用途之外，进一步说明为什么值得看这份清单，例如原素材中不同于惯常选择的取舍、一物替代多物的用途、具体使用结果或可验证的筛选理由。不能只说“分享几件方便好用的东西”，也不能无依据承诺“必须买／别人绝不告诉你”。

开头弱且素材支持不同入口时，内部比较 2—3 个具体开头，放进第一轮方向单，每个方向给开头示范并推荐一个（说明会让人想知道什么、材料依据及正文如何承接）；学员选定后再完成全文。原开头已有效时保留，不机械给多方案。只有一个有依据的入口时直接推荐，不凑数。不能把不适配当前正文的备选当成直接替换句。后续按局部复改规则选择和整合，不一口气生成多篇整稿。

## 根据实际内容形态判断

### 阶段／时间线攻略

- 每个阶段说清它与上一阶段**哪里不同**：什么时候开始考虑、家长能看到什么、接着怎么试、没按预想发展怎么办。月龄可以是背景，不能代替观察条件。
- 多个阶段不必等量展开。挑真正影响决策的节点讲深；重复的动作合并。时间轴或清单可在观众需要回看时收尾，不是固定花字。
- 核对专业、医疗、喂养与安全建议的来源；历史稿里的具体建议不能当作已证实知识。

### 清单／避坑／购买攻略

- 每项至少回答一个真正的选择问题：要不要、适合谁、何时用、带多少、为什么、替代办法。并非六项都必须写全，选择最能改变决定的那一项。
- “不推荐”要说在什么情况下不好用、自己怎么发现，以及能换什么做法；不要只列厌恶情绪。“推荐”要讲为什么在这个阶段或场景值得留。
- 清单主体有效时保留；若题目承诺具体数量、年龄、价格或阶段，逐项核对正文兑现。前一两项必须让目标读者看到这篇有新的判断，不靠统一夸张开场。

### 好物／书单／工具合集

- 先找合集共同的筛选理由，再看每件是否有**不同的任务、使用时刻或证据**。绘本可用孩子的实际反应，出行玩具可用坐车、等位等时刻，工具可用它实际替作者省掉的步骤。
- 同一套“好用、方便、解放妈妈”反复套在每件上时，删空话，留下最有辨识度的一点。真实使用证据不足就缩小主张，不替作者补试用经历。
- 顺序由读者最急的决策、真实时间线或场景变化决定。第一件弱时可调整，但不要打乱已有有效逻辑。
- 逐件检查、详略、排品和篇幅按 [内容增强与篇幅](enhancement.md) 处理。

### 观点／育儿方法

- 判断作者是在表达立场，还是承诺给别人建议。纯表达可以让真实现场、犹豫和选择支撑观点；给建议就要说观众能观察什么、怎么做、什么情况不适用。
- 金句或大观点若一开口像说教，可以先用**原稿已有的真实小事**引出：当时谁做了什么、作者怎样判断、结果让她改变了什么看法。没有亲历不能把示例场景写成发生过的事实。
- 把抽象术语和多层口诀尽量顺成一个具体场景里的连续动作。一段里有真实案例就不必再叠名人背书；证据只支持它实际能支持的范围。

### 个人经历／故事／Vlog

- 保留作者真有的口气、关系和生活纹理。梳理“原本怎么想 → 发生什么 → 新信息／困难 → 怎样选择 → 结果或现在的认识”，只留解释转折的细节，不把每个日常动作都写进去。
- 一篇经历可以让人陪伴、共情或认识作者，不强迫变教程。若标题承诺“经验／攻略”，才补观众可参考的条件和判断。
- 对生产、喂养、护理等经历，分开“我观察到什么”“我当时怎么想”“专业因果是否已证实”。不将个人处理方式写成适用所有人的办法，也不以“必须坚持”替别人做决定。

### 两种办法的比较／选择建议

- 先确定同一把尺子：这位作者和目标读者真正要解决什么问题。围绕这条尺子比较两边的收益、代价和适用条件，不能各说一串优缺点后不给选择依据。
- 对读者承诺“探园怎么问”等具体决策时，给能问出口的问题，以及回答如何影响判断；“多看环境”不够。

## 结尾与目标

- 攻略完成在读者能决定下一步；清单完成在能取舍；故事完成在变化或感受被看见；观点完成在具体判断被说清。没有必要统一“点赞收藏关注／下期想听什么”。后续内容确有连续价值时，可说明下篇还会解决什么。
- **收藏理由**看是否有可回查的条件、步骤或清单；**转发理由**看是否帮同处境的人解释一个问题；**讨论理由**看是否有真实选择分歧；**关注理由**看作者是否呈现出可持续的观察、经验或表达。分别判断，别把它们合成“传播性强”。
- **认识作者**看这一篇是否留下她真实的视角、口气或经历；**商业价值**只能初步看她的受众、选品判断和信任依据是否清楚。是否涨粉、爆发、获得合作或转化，需要账号背景、发布数据和实际反馈，不能靠稿子保证。

## 选择改动幅度

主体判断已成立、入口或结尾弱：局部改。承诺成立但证据分散：重排。正确却空：先补来源内的可见细节，补不出就缩小题目或标待补。标题与现有材料根本不匹配：换角度，但新角度仍须由原稿支撑。成稿反查每段是否回答本篇任务，合并重复后再核对数量、阶段与因果。


## 被问“离爆款差几步”时

日常笔记如果被问「离爆款差几步」「能不能涨粉／立人设／产生商业价值」，回答文本中可观察到的吸引、收获、分享或关注理由，并说明需要账号背景或发布数据才能判断的部分。不给没有依据的爆款分数、概率或效果保证。
