# 拆解底座：它为什么火，要仿什么

三类内容都先用这里的方法找原因、定「你要仿的」，再按类型文件细拆。这里的判断问题参考了「人类最强编导」的用户心理与 Vlog 方法、dbskill 的内容价值诊断与 3×3 内容影响力，已改写成本 Skill 的用法。第一到三节是你判断用的工具，不按这个顺序写给学员；写给学员的是第四、五节的结果。

## 一、为什么停下来

开头不是一句话。标题、封面、第一句或第一帧、声音，一起向观众承诺「接下来有什么」。

先把后面盖住，只看开头，回答：

1. 观众以为接下来要讲什么？
2. 这件事原本就在多少人脑子里？
3. 它和观众什么关系：她正在经历；关系到她的钱、风险、孩子、关系；说出了她有过但没说清的感受；让她确认自己是哪类人
4. 她预期看下去能得到什么？

让人停下来的，通常是这几种之一，最多两三种叠在一起：

| 类型 | 是什么 | 例子 |
| --- | --- | --- |
| 认同 | 说出她本来就信、但没说清的话 | 「当妈以后，我最怕的不是累，是没人觉得我累」 |
| 痛点 | 戳中她正在发生的麻烦 | 孕晚期弯不下腰穿鞋 |
| 没想明白 | 她不知道、想不通、或者想反驳 | 「孩子哭，我现在先不抱」 |
| 不同的生活 | 她没过过的身份、地方、日子 | 海岛上带娃、住房车 |
| 人物吸引力 | 人好看、有特点、第一句就好笑 | — |
| 画面和声音 | 可爱、好看、少见的画面，或者打断信息流的声音 | 改造前后的房间 |
| 猎奇 | 足够反常少见，但不让人不适 | — |

看着炸、却留不住人的开头：话题讲烂了，一看就知道后面没新东西；只有刺激，没说清跟我有什么关系；画面吵闹、让人不舒服。

## 二、为什么看下去

停下来只管第一秒，看下去靠后面一直兑现。按内容类型看：

| 类型 | 能让人看下去 | 让人划走 |
| --- | --- | --- |
| 信息型（攻略、清单、干货、好物） | 每段都让她多知道一点、离答案近一点 | 都是知道的；只有大词；开头承诺了答案，中间迟迟不给 |
| 情绪型（观点、关系、心路） | 同一种感受一层层加深 | 情绪刚起来，突然变成讲道理 |
| 故事和 Vlog | 有主线，观众知道这一期在等什么；人有目标、阻力、选择、结果；有新变化 | 和预想一样；拖着不推进；流水账 |

## 三、看完换来什么

观众看完做了什么，说明这条内容主要改变了她什么：

| 观众的动作 | 通常是因为 | 内容主要改的是 |
| --- | --- | --- |
| 收藏 | 有用，以后要用；一次没看懂 | 她知道了一件事 |
| 照着做、照着买 | 办法清楚，她觉得自己也能做 | 她的一个动作 |
| 评论 | 特别认同或特别反对；想说自己的事 | 她的一个看法 |
| 转发 | 想 @ 某个人；觉得对家人朋友有用 | 她想让别人也知道 |
| 关注 | 相信这个人以后还会给同样的东西（干货、生活方式、说话方式、系列） | 她对这个人的期待 |
| 认同到愿意买单 | 觉得「我就是这种人」「我也想成为这种人」 | 她怎么看自己 |

评论区能验证这一步：前排评论在问什么、吵什么、@ 了谁。

## 四、它为什么火：从四处找

| 从哪找 | 看什么 | 什么时候不拆 |
| --- | --- | --- |
| 选题 | 这件事原本在多少人脑子里、圈的是谁、带不带情绪；标题、封面文字、配文答应了什么 | — |
| 说话的人 | 见下面「说话的人」 | 纯干货、比参数的测评，人不是主要原因时，一两句带过 |
| 场景 | 家、店、路上这些环境本身是不是看点，满足的是好奇、窥探还是向往 | 看不到画面时不拆，写「画面没看到」；后面也不再写任何画面、镜头、动作 |
| 写法或拍法 | 开头怎么留人、怎么推进、怎么证明；Vlog 还看视角、有没有口播、有没有固定动作 | 拍法只在看得到画面时拆 |

- 只写真正起作用的，一般两到四处，标出最核心的一处；不四处都硬凑
- 每个原因都落到原文：摘一小句，或写清时间点和画面
- 依据：和自己有关的信息更容易被注意（选题）；观众会对屏幕上的人产生像熟人一样的感觉（说话的人）

### 说话的人：四项写在一处

放在「它为什么火」里，固定写成一块，四项各一行，每项摘一句原话：

```
**说话的人**
- 身份：她是谁，观众凭什么信她（不能借，换成学员自己的）
- 态度：她对这件事怎么看（学员真这么想才用）
- 说话习惯：用词、句子长短、口音、口头禅（不借）
- 手法：怎么让人笑、让人信、让人跟着看，例如自嘲、替观众说出质疑、拿日常东西打比方、把感受说成动作（能学）
```

- 四项都写在这一块里，不分到「选题」「仿不了的」；「仿不了的」只写一句「身份和口头禅见上面」
- 人不是主要原因时（纯干货、比参数的测评），这一块照样写，每项半句
- 只有文字时，表情、语速、动作不拆

### 场景和视角（看得到画面时）

- 场景是看点时，写清观众在看什么，以及它是专门展示的，还是在日常动作里顺带出现的
- 第一视角让观众像住进了那个生活，但只有配上值得看的场景，或者有人对着镜头说话，它才算看点；场景普通又没人互动，第一视角撑不起来，不算爆点

## 五、从原因到「你要仿的」

每个火的原因都往下写一步：仿的时候必须留住什么作用。能带走的是作用（例如「第一样就把人留住」），不是原作者的东西（例如「第一样是钢丝抹布」）。依据：类比迁移靠的是关系相同，不是表面相同。

- **必须留住的**：按出场顺序，写出撑起它火的那几步，有几步写几步；每步一行，写「作用 → 你那里放什么」（只写放哪一类东西，或问她一个问题；她没说过的事不替她写），标出最核心的一步。每一步都要对得上「它为什么火」里写过的原因，凑不出来的不硬写
- **仿不了的**：原作者的事、身份、人设，以及场景本身。场景或人设就是主要原因、学员又没有时，直接说「这个点你押不了」，再说她能押什么

## 六、写的时候

- 每个判断落到「原作具体做了什么 → 观众为什么停下、看下去、做了什么」，不写「共鸣、反差、情绪价值、节奏快、画面高级」
- **原作的事也要在原文里找得到**，交出前对一遍：
  - 加引号的只能是原文一字不差的话；自己的概括不加引号
  - 原作者说「你」「姐妹」「如果你是……」「大概率」，是在对观众说，不写成她自己的经历
  - 原文没有的数字、价格不写；东西用原文的叫法，不自己改名
- 推断和评论、数据对不上时，不下结论，写成「评论里有人在问……，说明这点还没讲透」。依据：人容易只找支持自己结论的证据
- 这些分类名是给你判断用的，对学员说的时候用大白话
