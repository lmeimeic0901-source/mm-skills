# 日常口播：拆解与能不能仿

先读 [拆解底座](lens.md)。学员想做以后的示范和陪练，见 [示范与陪练](coach.md)。本文件的例子都是教学虚构，不能当成用户事实，也不能套用台词。

拆解的目的是让学员看懂「人家为什么火」，知道「我要仿的是什么」，再知道「换成我的怎么写」。不是让她照着一样换一样。

## 一、《爆款拆解》

按主文件的四部分交。

### 1. 它为什么火

先一句话说完：「它让【谁】在开头关心【什么】，一直等着【什么】，看完拿走【什么】」，可以说得更口语。再按 [拆解底座](lens.md) 第四节，从选题、说话的人、场景、写法里找出真正起作用的两到四处，标出最核心的一处。每处只写一两句；说话的人按拆解底座的固定格子写。看不到画面时，场景不拆。

- 太空：「引发宝妈共鸣，情绪价值拉满。」
- 能用：「**写法：先给反直觉的做法**。第一句『我女儿哭，我现在先等十秒』，当妈的人马上想『这样行吗』，一直等她讲理由。」

评论区：学员给了才用，只挑前排真正有信息的一两条当证据，例如「前排一半在聊第一样，说明它确实留住了人」。没给就不提。

### 2. 你要仿的是什么

按 [拆解底座](lens.md) 第五节写：

- **必须留住的**：按 [拆解底座](lens.md) 第五节写，有几步写几步
- **可以借的原话**：挑一到三句说得好、学员自己不一定说得出来的，标「原作的话，你认同就用」；不选原作者的独家梗和口头禅。没有就不写
- **仿不了的**：原作者发生过的事——私人经历、人物、对话、数字、用出来的效果，还有身份、人设和资源

### 3. 每一段是怎么讲的

有时间点的写大约讲了多久，只有文字的写大约多少字。

**好物、清单、合集、评级：每一样都拆。**

先用一句话看篇幅：哪几样讲得透、哪几样压短，有没有哪段长得反常，为什么（例如在逗人、立人设）。

主的品写一块：

```
**第 X 样 名称｜大约多久｜主**
- 推荐理由：第一句给了什么理由
- 先讲麻烦：之前用什么、哪一下让人烦
- 日子怎么变：讲到有了它生活变成什么样，还是只在列功能
- 怎么证明：讲原理、用之前和之后、使用痕迹、价格、主动说的缺点
- 换成你的：这个位置放你的什么，再问一个能挖出她材料的问题
```

- 原作没做到的项，写一句「这一样没讲……，靠的是……」，不硬填
- 次的品每样只写一行：它在清单里的角色（开场、平时用的、救急的、便宜小件、笑点、收尾），为什么只讲这么点
- 依据：功能 → 带来的结果 → 对人的意义，讲到后两层才让人想要

**观点、经历、关系、心路、攻略、流程：先架构，再主段。**

架构表：

| 位置 | 做了什么 | 大约多久 | 主／次 |
| --- | --- | --- | --- |

- **做了什么**：按原顺序写出它的判断、现场、比较、转折、限制，不能只写主题
- 表下用一句话说清它是怎么一层层推进的，例如「先疼，再更疼，再换成尴尬，最后讲到没了自由」
- **主／次**：主是爆点所在，删了观众就拿不到回报，一般两到四处。标主之前问：这段删掉，观众还会等到同一个答案吗？还会，就是次

主段每段写一块，次段一行带过：

```
**位置｜给这段起个短名字｜主**
- 它做了什么：具体动作和顺序，只摘一小句原文帮学员认出是哪段，不把原文整段复述
- 为什么有效：观众这时候心里发生了什么
- 换成你的：这个位置放什么类型、什么角色的东西或经历，再问一个能挖出她自己材料的问题
```

### 4. 换成你的

两三个问题，让她能接着往下想：选题怎么换成她的处境、主要的位置放她的什么、她自己的说话方式（例如「身边的人会怎么形容你说话？」）。

「换成你的」只写类型和角色，**不写原作的品类，也不写原作者的处境**：

- 不好：「你也说说你穿什么鞋」「你也讲讲你被『孕妇必买』推送的经历」
- 好：「这里放一样你身体变了以后才离不开的东西，不一定是鞋。你之前用什么、为什么不行？它有没有一点不完美你也认了？」

问的问题要让她想起一件具体的事，**不替她预设答案**：问题里不能先假定她做过、变过、现在还怎样。

- 不好：「你现在哪件事不跟老公较真了？」（先假定她已经不较真了）
- 好：「有没有哪一次你没较真，后来怎么样了？你现在还会较真吗？」

## 二、学员想做：先判断能不能仿

| 爆点主要靠 | 学员需要有 | 没有怎么办 |
| --- | --- | --- |
| 题目或观点本身 | 她真心认同的判断，加一件能证明它的事 | 门槛低，多数人能仿 |
| 方法、清单、好物、攻略 | 她真用过、真做过，说得出具体差别 | 没用过不能装用过；可以只借题，讲她实际用的 |
| 一段特定经历或关系 | 有同类经历 | 只能借题，换成她有的经历回答同一个问题 |
| 身份、人设、资源 | 同等身份或资源 | 这个爆点借不了 |
| 画面或场景反差 | 能拍出同等程度的画面 | 拍不出就别押这个点 |
| 热点、时效 | 当下还在热度里 | 过了只借思路 |

结论三档：**可以仿**／**只能借题**（写清换成她的什么）／**不建议仿**（原因一句，再给一个她能做的近邻方向）。还没有她的材料时，写「要仿这条，你得有______」，再问一个能判断她有没有的问题。不建议仿时说得直接，不绕弯。

能仿或能借题，接着读 [示范与陪练](coach.md)。
