# 广告：拆创意、产品怎么出现、怎么证明、怎么拍

先读 [拆解底座](lens.md)。事实、借用和交接单规矩按主文件执行。例子都是教学虚构。

广告拆解是为了让学员看懂：这条广告用了什么创意、什么手法、什么道具，把产品讲出来、证明出来，为什么有效。**不写广告稿，也不在这里陪练**：广告有 Brief 和卖点要求，共创交给广告教练和测评探访教练。

## 一、《爆款拆解》

按主文件的四部分交，下面各小节是拆的材料，这样放：

| 部分 | 放哪几小节 |
| --- | --- |
| 它为什么火 | 1 一句话、2 形式、3 创意、7 说话的人和场景、8 这条广告的优势；再看观众处在买东西的哪一步（刚需、已经在挑在比、还没意识到需要），它决定广告怎么开头 |
| 你要仿的是什么 | 9 能借什么、不能借什么 |
| 每一段是怎么讲的 | 4 产品怎么出现、5 卖点和证明、6 画面；每一条卖点都拆，标大约讲了多久 |
| 换成你的 | 她的产品、她凭什么说、她的说话方式，两三个问题；想做时按第二节走 |

### 1. 一句话

「它用【什么场景／冲突／形式】把【产品】带出来，让【谁】相信【什么】，最后想【买／收藏／去了解】」

### 2. 广告形式

好物分享、合集、科普干货、选购指南、生活场景、单品测评、横测、探店、探厂、检测中心、剧情……写一个主形式；混合的写清哪个为主。

### 3. 创意

- 这条的主意是什么：用一个什么场景、冲突、问题、反差，让产品出现得有理由
- 观众为什么会停下来（用拆解底座第一节）

### 4. 产品怎么出现

| 问题 | 要写清 |
| --- | --- |
| 什么时候出现 | 大概第几秒、在第几段 |
| 出现前发生了什么 | 谁、在什么情况下、遇到了什么麻烦 |
| 以什么理由出现 | 解决那个麻烦？被拿来对比？自然用到？还是硬插 |
| 出现后人物还真实吗 | 语气、动作有没有突然变成念广告 |
| 用之前和用之后 | 有没有让观众看到变化 |

### 5. 卖点和证明

- 讲透了哪一两个卖点，其余的怎么处理（一句带过、字幕、画面）
- 怎么证明：

| 手法 | 例子 |
| --- | --- |
| 对比 | 和旧的、常见的、别家的放一起比 |
| 实验 | 倒热水、倒置、摔、泼水、拉扯 |
| 道具 | 温度计、秤、计时器、白纸、放大镜 |
| 使用前后 | 用之前什么样，用之后什么样 |
| 场景代入 | 放进真实生活里用给你看 |
| 第三方 | 检测报告、机构、专业人士 |

写清这条用了哪几种、用了什么道具、证明的是哪个卖点。测评、探店、探厂类单独写清测试步骤或探访路线。

**每一条都拆：** 先一句话看篇幅，哪几条讲透、哪几条带过。讲透的写一块：这条讲了什么、怎么证明、哪句最有用；带过的几条合在一起写一两行。开头和结尾各一行：开头怎么交代自己站在哪边，结尾有没有推荐、有没有留空。

### 6. 画面怎么呈现

挑三到六个关键画面，不逐帧：

| 大概位置 | 画面 | 起什么作用 |
| --- | --- | --- |
| 例：开头 | 孩子把杯子从桌上碰掉 | 让人马上想到「我家也这样」 |

常见作用：交代麻烦、产品特写、使用过程、对比结果、环境氛围、人物反应。

### 7. 说话的人和场景

- 说话的人：按 [拆解底座](lens.md) 第四节拆四项（身份、态度、说话习惯、手法），观众凭什么信她；语气是分享、带人选、还是讲道理
- 场景：在哪拍，场景对说服起了什么作用；看不到画面不拆

### 8. 这条广告的优势

两到三条，说清它为什么有效。例如「先让人看到杯子摔了，再测摔，证明顺序和观众担心的顺序一致」。

### 9. 能借什么、不能借什么

- 能借：创意思路、产品出现的方式、证明手法、道具、拍法、结构
- 不能借：品牌专属素材、达人身份和资源、场地、专业设备、原文案、他们的测试数据
- 先写「必须留住的」（[拆解底座](lens.md) 第五节，按出场顺序，有几步写几步），再写能借和不能借
- 原作说别家「骗人」「不行」这类话，提醒学员要有依据才能说

最后一行按主文件固定问，写「类似的广告」。

## 二、学员想做：三条路，让她选

先问还不知道的，最多两个：你的产品是什么（品牌、品类）？有 Brief 吗？

再给她三条路，写清每条适合什么情况，推荐一条，由她选：

| 她的情况 | 走哪条路 |
| --- | --- |
| 有想法、能自己写；产品和形式跟拆的这条差不多 | **自己写** → 写完连同 Brief 交给美美学员改稿审 |
| 没想法，或者换了产品，不知道这个思路怎么套 | **mm广告教练**：好物分享、合集、科普干货、选购、生活场景、美美小黑板 |
| 单品测评、探店、探厂、检测中心，要自己设计测试 | **mm测评探访教练**：测试怎么设计才安全、结果怎么说才不过头，它管得最细 |

- 横测、多品牌比较：给她两个选择——用 mm广告教练做合集，或者改成单品测评交给 mm测评探访教练
- 不替她想产品卖点，不编她的使用经历；她没说过的写【 】
- 不管她选哪条路，这个 Skill 都不陪她拍、不陪她写稿或旁白；有合作产品的 Vlog 也一样
- 有的手法要靠一件事才成立，例如「用了很久还没闲置」的反差，要她真的一直在用。这种手法可以借，但那件事要问她，不替她写成已经发生：提醒和交接里写「你这三个月是天天在用吗？是的话，这个反差就能用」，不写「你用三个月没闲置」
- 要自己设计测试、但想自己写的：提醒她测试的安全和结果说法容易出问题，建议至少先过一遍 mm测评探访教练

## 三、交接

### 她选自己写

不出整份交接单。给她一句提醒和一段可复制的话：

> 写的时候照着拆解里的手法来：创意怎么让产品出现得有理由、用什么证明、哪几个画面最关键。写完连同 Brief 一起发给美美学员改稿。

```
【交给：美美学员改稿】
这是我自己写的广告稿，Brief 一起发你，请帮我审一下、改一下。
我参考了一条广告的思路（只是手法，不是原文）：……
我真实用过的感受：……（只写她说过的原话，没有就写【 】）

我的稿：
……
```

### 她选广告教练或测评探访教练

```
【交给：mm广告教练】（或 mm测评探访教练）
我要做一条广告，请按你的流程先给我创意。

产品：……（品牌、品类）
Brief：我会一起发／还没有
想做的形式：……

参考的创意思路（来自我拆过的一条广告，只是方向，不照搬）：
- 创意：……
- 产品出现方式：……
- 证明手法和道具：……
- 拍法：……
- 人物状态：……

不能照搬：……
我手上有的：……（真实用过的感受、能拍的场景和条件；没说就写【 】）
还缺：……
```

- 参考思路只写手法和作用，不写原广告的台词、数据和品牌名，也不把原作的效果（例如「一年没闲置」）安到她身上
- 交接单前面不写处理过程，直接给
- 后面一句：「把上面整段复制到新对话，连同 Brief 一起发，调用 mm广告教练（或 mm测评探访教练）就行。」
